# 关于算法题

对于绝大多数算法题，往往需要把问题分成

```
题目
v
建模
v
主体逻辑
v
边界情况
v
实现细节
v
优化
```

1. 建模：本质是个什么问题
2. 主体逻辑：如果不考虑各种特殊情况，这道题最核心的规律是什么
3. 边界情况：这个逻辑在哪些地方失效
4. 实现细节：把想法正确地实现出来
5. 优化：降低复杂度

算法题本质就是在这五步上做文章

## 优化

暴力解是拿到题根据题意第一轮思考想到的，是兜底的正确解\
但暴力解是否通过需要看问题的规模\
优化所做的事情就是避免重复计算，避免空间浪费\
复用与状态压缩：发现状态之间的递推关系，这违反直觉，需要刻意找\
暴力的本质是：每个状态都从零重建，转移代价是从头计算\
优化的本质是：找到状态之间的递推，把转移代价降到最低\
这是绝大部分算法优化的本质\
所谓状态，就是描述当前进展到哪了所需的最小信息集合，换句话说，就是决定未来怎么走所依赖的全部过去信息：凡是影响后续计算的信息，就必须进状态；凡是不影响后续的，都可以扔掉
